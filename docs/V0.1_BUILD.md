# v0.1 Windows portable build

Use the project's Python 3.11 virtual environment.

1. Install PyInstaller: `python -m pip install pyinstaller`
2. Optional: add `assets/branding/demucs_studio_icon.ico` for the Windows executable icon.
3. Build: `pyinstaller Demucs-Studio.spec --noconfirm`
4. Test the resulting `dist/Demucs-Studio-v0.1-win64/` folder on a clean Windows account.

The build is intentionally **onedir**, not onefile. PyTorch, Qt Multimedia, Demucs and CUDA dependencies are large and are substantially easier to diagnose in a portable folder. Model checkpoints remain in the normal Demucs cache and are downloaded on demand.

Before publishing v0.1, verify: startup, CUDA/CPU detection, model download, separation, cancellation, DrumSep, library reopen, audition, waveform seeking, export mix, FFmpeg diagnostics and missing-file handling.
